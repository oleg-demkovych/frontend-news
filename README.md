# Фронтенд-стрічка

Новини, статті, пости та релізи зі світу фронтенду. Оновлення щогодини.

## Запуск на комп'ютері
Потрібен Node.js 20+. Встановлювати пакети не треба.

    node server.mjs

Відкрийте http://localhost:3000. Поки сервер працює, новини збираються щогодини.

## Безкоштовно в інтернеті (GitHub Pages)
1. Створіть репозиторій на GitHub і завантажте туди весь вміст цієї теки (разом із `.github`), гілка `main`.
2. Settings → Pages → Source: **GitHub Actions**.
3. Вкладка Actions → «Оновлення новин» → Run workflow.

Далі сайт оновлюється за розкладом щогодини. GitHub може запускати розклад із затримкою,
а в публічному репозиторії без активності 60 днів вимикає його (вмикається кнопкою в Actions).

## Без сервера
Якщо просто відкрити `public/index.html`, застосунок читає напряму з браузера тільки DEV Community та Hacker News.
CSS-Tricks, SitePoint і Reddit вилучено: вони не віддавали стрічки серверу GitHub.

## Джерела
Список у `scripts/sources.json`: `name`, `cat`, `url`, необов'язково `filter` (регулярний вираз) і `max`.
Які джерела не відповіли, видно в консолі та в застосунку внизу сторінки.
